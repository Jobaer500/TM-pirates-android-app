# TM Pirates – Official Android App (APK)

Official Android app for [TM Pirates](https://tmpirates.com): fast game diamond and gift card top-ups, order status alerts and one-tap Google login.

**[⬇ Download the latest APK](../../releases/latest)** · **[Install guide](https://tmpirates.com/app)** · **[Visit the website](https://tmpirates.com)**

## Features

- **Order alerts** – get notified when your order status changes
- **One-tap login** – sign in with your Google account
- **Faster to open** – launch the shop from your home screen
- **Easy updates** – new versions install from inside the app

## Requirements

- Android 7.0 or newer
- At least 100 MB of free storage

## How to install

1. Open the [latest release](../../releases/latest) in **Chrome** on your Android phone and tap the `.apk` file under **Assets**.
2. If Chrome warns about the file type, tap **Download anyway**.
3. Open the downloaded file. If asked, turn on **Allow from this source** for Chrome.
4. If Play Protect shows a warning, tap **More details → Install anyway**.

The app is not on Google Play, so Android shows its standard warnings for apps installed from outside the store.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| Download does not start | Open the link in Chrome, not inside Facebook, Messenger, Telegram or Instagram |
| "App not installed" | Free up 100 MB, uninstall any older TM Pirates app, download the file again |
| Samsung blocks the install | Settings → Security and privacy → Auto Blocker → turn off, install, turn back on |
| Xiaomi / Redmi / POCO security screen | Tap **Continue** or **Install anyway** and wait for the scan to finish |
